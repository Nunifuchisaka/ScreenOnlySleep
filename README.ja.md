# ScreenOnlySleep

[English](README.md) | 日本語

ScreenOnlySleep は、ホットキーで画面だけを黒くするツールです。PC はスリープしないので、ダウンロード、レンダリング、配信、自動操作はそのまま動き続けます。キーを押すかマウスのボタンを押すと、画面が戻ります。

Windows 10 / 11 のタスクトレイに常駐する小さなアプリです。

## できること

- ホットキー（既定は **Ctrl+Alt+F12**）を押すか、トレイのメニューで「今すぐ画面オフ」を選ぶと、すべてのモニターを黒いウィンドウで覆います。
- DDC/CI に対応したモニターは、輝度も 0 にしてバックライトを暗くします。解除すると元の輝度に戻ります。
- 本物のキーかマウスのボタンを押すと、画面が戻ります。解除に使った操作は捨てるので、下のアプリには届きません。
- 安全のため、12 時間たつと自動で解除します（時間は変えられます）。

## マウスを動かしても点かない理由

Windows の「ディスプレイの電源を切る」は、マウスが少し動いただけで点きます。机が揺れたり、センサーがぶれたりしても点きます。ScreenOnlySleep は、Windows から見たディスプレイの電源を切りません。上に黒いウィンドウを重ねて、入力を自分で見ています。

- マウスの移動とホイールでは解除しません。
- 合成された入力でも解除しません。`SendInput` などで送られ、Windows が「注入」の印を付けた入力のことです。自動操作のツール、キーの割り当てを変えるソフト、スリープを防ぐツールが送る入力がこれに当たります。
- F13〜F24 と、普通のキーボードからは出ないいくつかの仮想キーでも解除しません。
- ホットキーを押したあとは、そのキーがすべて離されるまで解除の判定を始めません。キーリピートですぐに戻ってしまうのを防ぐためです。

黒いウィンドウはクリックを下へ通し、フォーカスを奪わず、スクリーンショットにも写りません。画面が暗い間に別のプログラムがデスクトップを自動操作していても、そのプログラムからは下の本物のウィンドウが見え、クリックもできます。

## 導入

1. Releases のページから `ScreenOnlySleep-<バージョン>.zip` をダウンロードし、置いておくフォルダーに展開します（例：`%LOCALAPPDATA%\Programs\ScreenOnlySleep`）。
2. `ScreenOnlySleep.exe` を起動します。タスクトレイに月のアイコンが出ます。
3. Windows の起動時に自動で起動したいときは、トレイのメニューから「設定」を開き、「Windows の起動時に自動で起動する」にチェックを入れます。

.NET Framework 4.8 で動きます。Windows 10（May 2019 Update 以降）と Windows 11 には最初から入っているので、ほかに入れるものはありません。黒いウィンドウをスクリーンショットに写さない機能は、Windows 10 バージョン 2004 以降で働きます。

exe にはコード署名がないため、初回の起動で SmartScreen の警告が出ることがあります。

## アンインストール

1. 「設定」で「Windows の起動時に自動で起動する」のチェックを外し、トレイのメニューから「終了」を選びます。
2. `ScreenOnlySleep.exe` を置いたフォルダーを削除します。
3. `%LOCALAPPDATA%\ScreenOnlySleep`（設定とログ）を削除します。

チェックを外さずに exe を消してしまった場合は、`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` にある `ScreenOnlySleep` の値を削除してください。

## 設定

トレイのメニューから「設定」を開きます。

| 項目 | 既定 | 説明 |
|---|---|---|
| ホットキー | Ctrl+Alt+F12 | 入力欄をクリックして、新しい組み合わせを押します。Ctrl・Alt・Shift・Win のどれかと、ほかのキーの組み合わせにします。別のアプリが使っているキーなら、その旨が出るので別のキーを選べます。 |
| Windows の起動時に自動で起動する | オフ | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に値を追加、削除します。 |
| 対応モニターは輝度も 0 にする（DDC/CI） | オン | DDC/CI が使えないモニターは自動で見分け、黒いウィンドウだけにします。 |
| 自動解除までの時間 | 12 時間 | 安全のための自動解除です。0.25〜48 時間で設定できます。 |

設定、ログ、控えた輝度は `%LOCALAPPDATA%\ScreenOnlySleep\` に置きます。

- `settings.ini`：上の設定です。
- `ScreenOnlySleep.log`：解除に使った入力、見送った入力（件数に上限あり）、前面のウィンドウの変化を残します。解除したあとのキー入力は記録しません。
- `ddc-state.tsv`：元の輝度です。書き換える前に控えます。画面が暗い間にアプリが強制終了しても、次の起動で先に輝度を戻します。Windows のシャットダウンのときも戻します。

起動時に、別のアプリが使っているためホットキーを登録できなかったときは、通知で知らせます。その場合も、トレイのメニューからは使えます。

### コマンドライン

| オプション | 意味 |
|---|---|
| `--restore-only` | 控えた輝度に戻して終了します。 |
| `--data-dir <フォルダー>` | `%LOCALAPPDATA%\ScreenOnlySleep` の代わりに、指定したフォルダーを使います。 |
| `--test-seconds <n>` | トレイに常駐せずに 1 回だけ画面を暗くし、n 秒後に戻して終了します。 |

## 既知の制限

- マウスのカーソルは隠れません。黒い画面の上に表示されたままです。
- 画面が暗い間も、マウスの操作は下のアプリに届きます。移動とホイールはそのまま届き、解除に使ったクリックだけを捨てます。カーソルの位置に気をつけてください。
- 入力を注入するソフトの操作では解除されません。G HUB のキー割り当て、AutoHotkey、Deskflow（キーボードとマウスを共有するソフト）などがこれに当たります。その PC の本物のキーボードかマウスで操作してください。
- 通知などの最前面のウィンドウが、黒い画面より手前に一瞬出ることがあります。すぐに黒い画面で覆い直します。
- DDC/CI が使えないモニターは、黒いウィンドウで覆うだけなので、バックライトは点いたままです。画面は黒くても光っています。
- モニター、ドック、変換アダプターによっては、DDC/CI での輝度の変更が遅かったり、効かなかったりします。

## ビルド

Windows に .NET 8 SDK（以降）があればビルドできます。参照アセンブリのパッケージを使って .NET Framework 4.8 向けにビルドするので、Visual Studio は要りません。

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

単体テストを実行し、Release の exe をビルドして、`dist\ScreenOnlySleep-<バージョン>.zip` を作ります。テストだけを実行するときは次のとおりです。

```powershell
dotnet test
```

`v1.0.0` のようなタグを push すると、GitHub Actions のワークフローが zip をビルドし、exe と一緒に新しいリリースに添付します。
